# SF1+ art pack

The approved fighter poses are indexed PNGs whose indices are the fighter's palette pens. Pen 15 is transparent. `manifest.json` records the size and CRC-32 of each approved pose. The Windows ZIP contains the approved files and this manifest.

The repository also keeps PixelLab candidates in `candidates/` for art authoring. Generation records, prompts, references and approvals are under `art/` in the main repository.

The pack was imported from [sf1-port-art at 8fb731ff](https://github.com/johnstreetfighter/sf1-port-art/tree/8fb731ff37f6c07e3d87964b4bccac69e296d65b).
