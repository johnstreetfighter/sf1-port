# Sagat SFV moveset audit

This audit uses SFVSim's extracted Sagat action data and Capcom's dated balance notes. Port observations are static in the workspace at Git HEAD `0e336743760689ccdd192cbe4ebce5c4d638c9c4`. The paired fixture is Sagat versus Ryu in Training, Classic controls, Era Default gauges, with Ryu on the same SFV revision. The SFVSim extracts identify their version labels. Playable executable hashes, platform and paired traces remain unverified. ### V-Trigger execution clocks

Neutral activation `750`/`770` in August, Kage, Seth and Definitive lists 60 uninterrupted action frames. At tick zero the speed command lists 55 total frames, 100% self speed and 0% opponent speed. The decoder calculates opponent ticks as speed times duration. Zero opponent ticks means the opponent's action clock stays still during the command. The Seth normal cancel `751`/`771` uses 50 total, the 2MP/2MK routes `752`/`772` use 52, and the high/low Shot routes use 59/57 for VT-I and 57/53 for VT-II. In SFVSim, a successfully started activation sets the timer before the frame's final transition. On a neutral activation with neither side stunned, the timer first decrements on that same frame, before the speed command adds opponent stun. Further decrements pause until both stun counters clear.
