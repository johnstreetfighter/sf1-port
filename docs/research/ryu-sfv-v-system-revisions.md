# Ryu V-System across Street Fighter V revisions

This is a static source comparison for [#149](https://github.com/johnstreetfighter/sf1-port/issues/149). The port offers three Ryu cards. `SF5` has V-Skill I and V-Trigger I, `SF5 AE` adds V-Trigger II, and `SF5 CE` offers all four skill and trigger pairings. #138 used four source snapshots for pacing because it sampled two AE balances. The existing design expressly includes V-Shift and V-Shift Break on the CE card. The v5.012 Seth snapshot supplies a CE pacing comparison, and the v7.001 comparison in #138 gives the same ordinary light Hadoken recovery. A single full-game CE patch pin for the port card remains open. ## Late Champion Edition V-Shift

V-Shift starts in v6.001 on February 22, 2021. From a grounded actionable state, neutral `HP+MK` spends one V stock. After a successful evade, repeat or hold the chord for V-Shift Break. Capcom added forward and backward directional input in August 2021. The v6.001 and v7.001 Ryu scripts both show `1250` with armor `[0,9)` and a boundary of `31`, and `1251` with a 150-unit refund at tick 11 and a boundary of `23`. The separate Break strike `1252` is active `[20,23)` with boundary `46`. The half-stock refund agrees with late FAT. Its frame table leaves Break startup and total blank. [v6.001 release](https://game.capcom.com/cfn/sfv/systemfault/133131) · [V-Shift launch rules](https://game.capcom.com/cfn/sfv/adjust/ce202102?lang=en) · [August 2021 rules](https://game.capcom.com/cfn/sfv/adjust/ce202108?lang=en) · [Definitive Shift](https://sfvsim.com/diff/RYU/060/scripts/1250_V_SHIFT.html) · [Definitive evade](https://sfvsim.com/diff/RYU/060/scripts/1251_V_SHIFT_DODGE.html) · [Definitive Break](https://sfvsim.com/diff/RYU/060/scripts/1252_V_S_BREAK.html) · [Pinned late CE FAT](https://raw.githubusercontent.com/D4RKONION/FAT/dee6b85a7f8f166701ff3f8ab6cfa954949d99aa/src/js/constants/framedata/SFVFrameData.json)

The port matches the documented loadout progression and provides Shift and Break on the CE card. Seth predates those actions. The port's static Ryu path uses one Denjin duration of 1000 and a Kakko Fubatsu duration of 1500. It deducts 150 per Isshin activation and clears the install when the defensive counter starts its return strike. It also grants a +50 timer refund for a Mind's Eye parry during Denjin in every revision. That refund enters the source in February 2021. The port's shared blockstun chord accepts `6PPP` and `6KKK`, while Ryu's source command uses `6PPP`. The port's Skill I and Skill II counters initialize to 12 and 6 ticks, while the source has the separately offset armor windows above. These are static differences. Paired live action selection, freeze, hit and guard reactions, and exact cancel windows remain open. ## Reproduce the extraction

1. Fetch `index.html` for each linked SFVSim snapshot. Read `VGauge`, `VTrigger` and `VTrigger2` in the character header. The rendered `004`, `020`, `030` and `041` index SHA-256 hashes are `0f45706e3f62ecf321566a1db2398c5db03676bfa7948b5b02ae84de80cf5d3e`, `9f5d03cde4a54a168fb5750bdd599560771e592a33a9ae222594ac92145abaf7`, `07f995c38f1a4ce67435e377b82b29fd0c88afe67fa5ce7f1e8e431ef2bd76ad` and `2c19bf201de4d3b35f93fdd9df1985217921935a91287c63676ec728223fa326`. Winter `050` is `dc24d88c57e761f8dca38265e415521b5b36edda41314bddcdf98000e54a555c` and Definitive `060` is `65cee72fcce9aa0b09113803a162d6452c4e1882203e79873eb330c70853d610`.
2. Follow `moves/V_SKILL.html`, `V_SKILL_2.html`, `VT_RENKI.html`, `FBD_L.html`, `VT2_SHIN.html`, `VT_02_ATEMI.html` and `V_REVERSAL.html` as present in each index. Read the input icons, resource costs and linked script. The V-Shift action is listed by script ID. Divide the timeline lane's left position and width by 30 to obtain the script start and duration. Follow hit, whiff and armor branches before comparing elapsed timing. [Seth index](https://sfvsim.com/diff/RYU/041/) · [Definitive index](https://sfvsim.com/diff/RYU/060/)
3. In a live run, use Ryu versus Ken with Classic controls and Era Default gauges. Reset to fixed spacing and repeat each action facing both directions. For Skill I and Isshin, sweep the same `5LP`, `2LK`, jump-in and light Hadoken into the counter, with a throw as a control. Try guard-cancel `6PPP` and `6KKK` on the same blocked jab. Record neutral and `2MK` or `5MP` cancel activation separately. For CE record raw Shift, an evade, repeat versus held Break input, and a forward or back chord. Save the build identity, first accepted and rejected inputs, both fighters' freeze and movement, timer and V-Gauge changes, and port commit.
