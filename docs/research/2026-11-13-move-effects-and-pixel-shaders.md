# Free pixel-art move effects and shader references

Reviewed 2026-11-13 for Street Fighter′: The World Tournament. SpritePilot’s 16 px landing dust and parry flash are the best first candidates for Overhaul. The dust is only five pixels tall in its widest frame, and the parry crescent reads differently from a gold hit spark. The game’s 384 × 224 frame, native hit sparks, Hadoken impact, and Geki smoke provide a scale and palette reference. ## Shader effects in this renderer

The Rust renderer draws indexed sprites at native resolution. Overhaul already has per-fighter `PaletteTint`, three-pose `AfterimageTrail`, and a stage mask. SF3 already uses palette tint for parry and EX feedback. The wgpu picture shader and librashader receive a composited frame, so a fighter-specific shader needs sprite or mask data at an earlier step. The Rust compositor can express the first two effects below directly. [Compositor](../../crates/sf-video/src/compositor.rs) · [SF3 feedback](../../crates/sf-engine/src/era_fight/sf3.rs) · [GPU window](../../crates/sf-host/src/gpu_window.rs) · [Display looks](../../shaders/README.md)

| Effect | Reference and application |
| --- | --- |
| One-pixel inner outline | GodotLearning’s CC0 outline samples neighbouring texels and supports an inner edge. Apply the idea to the whole pose’s coverage so adjoining 16 × 16 tiles share an edge cleanly. A short blue-white edge could mark a perfect parry or charge completion. [Sprite Outline Shader](https://godotlearning.com/shaders/sprite-outline) |
| Dithered afterimage fade | The MIT `glsl-dither` examples provide 2 × 2 and 4 × 4 ordered thresholds. Try the threshold on trail coverage at native pixel coordinates while reusing the existing pose history and tint. Keep the MIT notice if copying code. [glsl-dither](https://github.com/hughsk/glsl-dither) · [License](https://github.com/hughsk/glsl-dither/blob/master/LICENSE.md) |
| Local impact ripple | The posted CC0 Distortion/Shockwave code shows how to animate a radial displacement. A small, integer-pixel displacement applied before HUD composition could suit a fully charged Super. A sprite ring is the easier visual comparison for the first pass. [Distortion/Shockwave](https://godotshaders.com/shader/distortion/) |
| Baked effects | CrunchyShader documents CC0 WebGL2 and Godot exports for outlines, burning, and dissolves. It can bake sprite effects to PNG strips for evaluation with the existing renderer. [CrunchyShader](https://sevi66.itch.io/crunchyshader) |

## First in-game comparison

Start in Definitive Overhaul with landing dust on a knockdown, a blue parry flash on SF3 Ryu, and the 16 px gold spark on a heavy normal. Compare each with the existing effect on a bright and a dark stage. Review the first visible frame at native resolution, then with the Arcade Cabinet look. The source hit spark plays at 15 fps, so judge the useful frames and their timing against actual contact before adopting the full animation. `FightRead` distinguishes landed hits and blocks, including guarded chip. Placement can use the existing contact-effect position or measured contact geometry. This pass inspected assets and renderer code. In-game fit and timing still need a playtest.
