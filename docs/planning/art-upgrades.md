# Art upgrades: compromises to redraw later

Every time the art pipeline (spec #164) ships a move that falls short of what new art could do, it is listed here. That covers reused or pieced ROM poses standing in where purpose-drawn sprites would be better, and generated poses accepted with known flaws. Once the game is complete with everything else the user wants, this list is the queue for new art generation (user, 2026-11-02).

**How an entry gets here.**
- When the user approves a move on the review page as serviceable rather than ideal, it is added.
- When the builder ships a move it knows is a compromise, it is added, with the reason.
- Each entry names the fighter and move, what ships now, what the better version would be, and where it was approved.
