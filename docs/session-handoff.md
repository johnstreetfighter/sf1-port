# Project handoff

- **Source version:** v1.3.3, the SF1+ edition of Street Fighter: The World Tournament. The Main Menu shows the edition prime and subtitle with extra spacing. Windows uses the Ryu icon for the executable and game window.
- **Online play:** Native 1v1 rollback, live spectating, and SF1+ Dramatic Battle co-op are implemented. Internet Versus rooms by code run through a QUIC relay (`sf-relay`, [ADR-0024](adr/0024-internet-rooms-through-a-quic-relay.md), #124 via #159). The Default relay is live at `relay.almamoto.com` (OVHcloud VPS-1, Vint Hill, Ubuntu 24.04; operator record on #130) and ships as `DEFAULT_RELAY` (#170), so Host Match's VISIBILITY starts on INTERNET CODE and tests that want a local room step right to PUBLIC. A Community relay can still be set under **Settings → Netplay → RELAY** (#128). The server was set up with `tools/relay/setup-ubuntu.sh` (#168; one fix from the first real run, `29f25bf`), runs the CI-built binary from the Relay workflow (#167), and that workflow checks it every six hours with `--check --min-days 14`. Spec #166's tickets #167 to #171 are all closed, with #128 and #130; the spec itself is still open. The live check (#171, 2026-11-17) ran two PCs on separate networks through the Default relay and a temporary second relay, since torn down; results are on #128 and #130. It found two lobby bugs, both fixed and re-checked on screen: relay names in failure messages are upper-cased because the font has capitals only (`7da6e53`), and a failed Internet join keeps the relay's failure on screen (`329a86a`). No tagged release contains the Default relay: v1.5.25 is marked pre-release, and a Windows-only v1.5.26 is next (ask before pushing its tag), then #127, #125, #129, #131, with macOS (#126, #132) deferred. The Relay workflow's scheduled runs now reuse a cached binary (`205159c`); a manual run passed, a scheduled run on the cached path has not happened yet. The script's `certbot reconfigure` path has never been run, load beyond one room is unmeasured, and the full suite was not rerun after the #171 fixes. `np5_sessions` overflows its stack in a debug build (#191) and passes optimized. The live public room directory remains unverified. See [Netplay](netplay.md).
- **Matchmaking:** Designed and ticketed, nothing built. Ranked and Unranked queues with CPU opponents when nobody is waiting, run by a separate matchmaking service beside the relay, with name-and-password accounts. Read the [design](design/2026-11-17-matchmaking-design.md), [ADR-0025](adr/0025-matchmaking-service-accounts-and-trusted-cpu-matches.md) and the Matchmaking section of `CONTEXT.md`. Spec #173; tickets MM1–MM17 are #174–#190 as sub-issues with blocked-by links. Only MM1 (#174, screen mock-ups) is unblocked, and George approves the mock-ups before MM2. MM17 (#190) is the live bring-up and is `ready-for-human`. Ask before pushing or closing MM tickets. The Street Fighter 6 ranked format the design copies came from memory and forum threads, not an official source.

Another session worked on #171 in the same checkout at the same time; its uncommitted edits to `crates/sf-engine/src/front/session.rs` and `crates/sf-engine/tests/internet_rooms.rs` were left alone.
