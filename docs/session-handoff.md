# Project handoff

- **Source version:** v1.3.3, the SF1+ edition of Street Fighter: The World Tournament. The Main Menu shows the edition prime and subtitle with extra spacing. Windows uses the Ryu icon for the executable and game window.
- **Online play:** Native 1v1 rollback, live spectating, and SF1+ Dramatic Battle co-op are implemented. Internet Versus rooms by code run through a QUIC relay (`sf-relay`, [ADR-0024](adr/0024-internet-rooms-through-a-quic-relay.md), #124 via #159). The Default relay is live at `relay.almamoto.com` (OVHcloud VPS-1, Vint Hill, Ubuntu 24.04; operator record on #130) and ships as `DEFAULT_RELAY` (#170), so Host Match's VISIBILITY starts on INTERNET CODE and tests that want a local room step right to PUBLIC. A Community relay can still be set under **Settings → Netplay → RELAY** (#128). The server was set up with `tools/relay/setup-ubuntu.sh` (#168; one fix from the first real run, `29f25bf`), runs the CI-built binary from the Relay workflow (#167), and that workflow checks it every six hours with `--check --min-days 14`. Spec #166's tickets #167 to #169 are closed. Still open: #171, the live check with two players on separate networks and a temporary second relay, which closes #128 and #130. No tagged release contains the Default relay; the tag belongs to #131, and v1.5.25 was published earlier with the RELAY setting but no default. The script's `certbot reconfigure` path and the guide's second-relay steps have never been run. `np5_sessions` overflows its stack in a debug build (it did before #170) and passes optimized. The live public room directory remains unverified. See [Netplay](netplay.md).
- **Latest session (2026-11-16):** Merged Super Turbo Ryu, Ken and Sagat timing (#157); two ST Ryu Hadoken whiff tests are ignored until ST Ken's jump hurtboxes are measured (#158). Merged Internet rooms (#159) and closed #124. `cargo suite` runs the full workspace optimized into `target/suite`. The suite's remaining failures need local fixtures (34 captures, the `sf1-port-art` folder for `evil_ryu_spike`) or predate these branches (the Dramatic KO overflow on main). `target/` links to `D:\sf1-port-storage`; D: filled up and 80 GB of old build caches were deleted.
- **Open work:** Use the [open issue crosswalk](planning/open-issues.md) for the active roadmap, including era styles, controller QA, and combo discovery.
- **Local fixtures:** Supply the ROM set and optional art, voice, and music packs locally. [Reference setup](../tools/reference/README.md) describes the ignored fixture paths.
- **Build and release:** Use a locked Cargo build. Follow the [Windows release guide](../tools/release/README.md) for packages from this repository.
