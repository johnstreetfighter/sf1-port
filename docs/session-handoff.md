# Project handoff

- **Source version:** v1.3.3, the SF1+ edition of Street Fighter: The World Tournament. The Main Menu shows the edition prime and subtitle with extra spacing. Windows uses the Ryu icon for the executable and game window.
- **Online play:** Native 1v1 rollback, live spectating, and SF1+ Dramatic Battle co-op are implemented. Internet Versus rooms by code now run through a QUIC relay (`sf-relay`, [ADR-0024](adr/0024-internet-rooms-through-a-quic-relay.md), #124 via #159); they appear only with `relay = "…"` in `settings.toml`, because no default relay runs yet (#130) and the relay menu is #128. Physical two-computer play, a relay on the real Internet, and the live public room directory remain unverified. See [Netplay](netplay.md).
- **Latest session (2026-11-16):** Merged Super Turbo Ryu, Ken and Sagat timing (#157); two ST Ryu Hadoken whiff tests are ignored until ST Ken's jump hurtboxes are measured (#158). Merged Internet rooms (#159) and closed #124. `cargo suite` runs the full workspace optimized into `target/suite`. The suite's remaining failures need local fixtures (34 captures, the `sf1-port-art` folder for `evil_ryu_spike`) or predate these branches (the Dramatic KO overflow on main). `target/` links to `D:\sf1-port-storage`; D: filled up and 80 GB of old build caches were deleted.
- **Open work:** Use the [open issue crosswalk](planning/open-issues.md) for the active roadmap, including era styles, controller QA, and combo discovery.
- **Local fixtures:** Supply the ROM set and optional art, voice, and music packs locally. [Reference setup](../tools/reference/README.md) describes the ignored fixture paths.
- **Build and release:** Use a locked Cargo build. Follow the [Windows release guide](../tools/release/README.md) for packages from this repository.
