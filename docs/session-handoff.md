# Project handoff

- **Source version:** v1.3.3, the SF1+ edition of Street Fighter: The World Tournament. The Main Menu shows the edition prime and subtitle with extra spacing. Windows uses the Ryu icon for the executable and game window.
- **Online play:** Native 1v1 rollback, live spectating, and SF1+ Dramatic Battle co-op are implemented. Physical two-computer play and the live public room directory remain unverified. See [Netplay](netplay.md).
- **Open work:** Use the [open issue crosswalk](planning/open-issues.md) for the active roadmap, including era styles, controller QA, and combo discovery.
- **Local fixtures:** Supply the ROM set and optional art, voice, and music packs locally. [Reference setup](../tools/reference/README.md) describes the ignored fixture paths.
- **Build and release:** Use a locked Cargo build. Follow the [Windows release guide](../tools/release/README.md) for packages from this repository.
