2. **MAME 0.289 Pre-Reset DIP Application (`tools/reference/lua_gen.py`, `tools/reference/run_scenario.py`):**
   - **Empirical check (`[cap]`):** In MAME 0.289 (`ioport.cpp`), `ioport_manager::frame_update()` runs during `ioport_manager::initialize()` (before `-autoboot_script` executes at `-autoboot_delay 0`) and on `MACHINE_NOTIFY_FRAME` (at the end of frame 0), not on `MACHINE_NOTIFY_RESET` (`machine:soft_reset()`). Writing `field.user_value` in Lua (with or without `machine:soft_reset()`) leaves `ports[":DSW1"]:read()` at `0xdfff` throughout frame 0 and only updates on frame 1.
   - **Adopted mechanism:** When `s.dipswitches_explicit` is `True`, `write_cfg(s, out_dir)` writes `<out_dir>/cfg/sf.cfg` (`<mameconfig version="10">`) before launching MAME and omits `-noreadconfig`. MAME's `configuration_manager::load_settings()` loads `cfg/sf.cfg` before `ioport_manager::initialize()`, so `ports[":DSW1"]:read()` and `ports[":DSW2"]:read()` equal the requested words before the 68000's reset, at frame 0 (`fn == 0`), and at the end of the run.
   - **Byte-identical existing drivers & explicit-default equivalence:** All 52 pre-existing scenarios (`dipswitches_explicit == False`) regenerate a byte-identical `generated_driver.lua`. Re-running `sf-fixed-fight-01` with all 13 default DIP fields stated explicitly matches `fight-run-a` byte-for-byte across all 73 observation files.
   - **Readback verification (`C-NEG`):** The generated Lua driver checks `ports[":DSW1"]:read()` and `ports[":DSW2"]:read()` at frame 0 (`fn == 0`) and at the end (`fn >= CONFIG.duration_frames`) against `CONFIG.dsw1` and `CONFIG.dsw2`, aborting the run before writing `meta.tsv` if either differs; `lua_gen.verify_readback` and `sf_compare::compare` also verify `meta.tsv`'s `dsw1` and `dsw2` against the scenario's `(dsw1, dsw2)`.
